## Architecture

This is a Next.js 16 ecommerce application with TypeScript, Tailwind CSS 4.1, and a complete backend integration stack.

### Core Integrations

- **Better Auth** (`src/lib/auth.ts`): Authentication layer using Drizzle adapter for PostgreSQL persistence. Exports `Session` and `User` types for type-safe usage throughout the app.
- **Drizzle ORM** (`src/db/`): Database layer with schema in `schema.ts`. Migrations live in `src/db/migrations/` (generated by drizzle-kit).
- **PostgreSQL via Neon**: Connection via `DATABASE_URL` env var. Schema is pushed with `npm run db:push`.

### File Organization

- `src/app/` - Next.js App Router (pages, layouts, API routes)
- `src/db/` - Drizzle schema definition and database client
- `src/lib/` - Configuration and utilities (auth, etc.)
- `src/components/` - React components (not yet populated)

### Environment Variables

Required in `.env.local`:
- `DATABASE_URL` - PostgreSQL connection string from Neon
- `BETTER_AUTH_SECRET` - Min 32 characters, used for auth signing
- `BETTER_AUTH_URL` - Base URL for auth callbacks (e.g., `http://localhost:3000` in dev)

## Common Commands

```bash
npm run dev              # Start dev server at :3000
npm run build            # Build for production
npm run start            # Run production build
npm run lint             # TypeScript & ESLint check
npm run db:generate      # Generate migration files from schema changes
npm run db:push          # Apply migrations to database
npm run db:studio        # Open Drizzle Studio browser UI for data inspection
```

## Development Workflow

1. **Schema Changes**: Modify `src/db/schema.ts`, run `npm run db:generate`, then `npm run db:push`
2. **Type Safety**: Auth and database types are exported from `src/lib/auth.ts` and `src/db/db.ts` for use in components/API routes
3. **API Routes**: Create in `src/app/api/` using Next.js conventions. Server-side only by default.
4. **Database Queries**: Import `db` from `@/db/db` and use Drizzle ORM syntax

## Key Tech Stack

- **Framework**: Next.js 16.4 with App Router
- **UI Library**: React 19 (stable release)
- **Styling**: Tailwind CSS 4.1 with PostCSS
- **Forms**: React Hook Form 7.56 + Zod 3.24 validation
- **ORM**: Drizzle ORM 0.45.4 with PostgreSQL driver (postgres-js)
- **Auth**: Better Auth 1.7.7 with Drizzle adapter (creates its own tables automatically)
- **Type Checking**: TypeScript 5.7 with strict mode enabled

## Database Connection

Uses `postgres-js` driver (faster, more modern than node-postgres). Connection via `postgres()` client in `src/db/db.ts`.

Drizzle config uses `dialect: "postgresql"` and `url` property instead of deprecated `driver` and `dbCredentials.connectionString`.

## Migration Workflow

```bash
npm run db:generate  # Generate migration files from schema changes
npm run db:push      # Apply migrations to database
npm run db:studio    # Inspect/manage data visually
```

## Minimum Node Version

- **Node.js 20.9.0+** required (Next.js 16 minimum)

## Setup After Cloning

1. `npm install` - Install dependencies
2. `cp .env.example .env.local` - Create env file
3. Fill in `DATABASE_URL` (Neon PostgreSQL) and generate `BETTER_AUTH_SECRET`
4. `npm run db:push` - Initialize database
5. `npm run dev` - Start development

## Known Limitations

- Better Auth schema: The adapter auto-generates auth-related tables on first use (don't manually define them in `src/db/schema.ts`)
- Tailwind v4: Uses new `@import "tailwindcss"` syntax in `globals.css`; no need for separate `@tailwind` directives
